What is this BST Visualizer?

    
This is a free, browser-based tool for visualizing and debugging binary search trees and n-ary trees written in Python. Unlike most tree visualizers, which only animate a fixed, pre-built algorithm, this tool runs your own code — paste any Python implementation of a binary search tree, an n-ary tree, or any recursive tree/graph structure, and it executes the real Python interpreter in your browser to trace exactly what your code does, line by line.

  

  

    
How it works

    
The tool uses Pyodide, a full CPython runtime compiled to WebAssembly, so your code runs as real Python — not a simulation or reimplementation. As execution proceeds, a line-level tracer inspects your live objects after every statement, automatically detects your tree's root variable, and reconstructs the tree structure by walking whatever attributes your node objects use for children and values. The result is a step-by-step debugger that shows the actual line executing, the live local variables in the current stack frame, the tree redrawn at every step, and the real recursion path highlighted as it moves through the tree.

  

  

    
Supported tree structures

    
Works with classic binary search trees using left/right child attributes (or dict-style keys), and with n-ary trees using a children list. Node values are read from common attribute names like val, value, data, key, or name. No special base class or library import is required — most conventional tree implementations work without modification.
